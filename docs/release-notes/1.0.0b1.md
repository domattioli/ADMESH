# ADMESH 1.0.0b1

Release date: 2026-10-01. This is the first 1.0 pre-release, a beta. The public API in `admesh.__all__` is fixed for 1.x.

```bash
pip install admesh2D==1.0.0b1
```

The full list of changes, including earlier releases, is in the [CHANGELOG](https://github.com/domattioli/ADMESH/blob/main/CHANGELOG.md).

## Changed

- The version is 1.0.0b1, with the `Development Status :: 4 - Beta` classifier.
- The 14 `admesh.<stage>` compatibility modules are kept for all of 1.x; removal is no earlier than 2.0. The canonical import path is `admesh._stages.<stage>`.
- `docs/api` documents every name in `admesh.__all__`, including `triangulate_batch` and the Gmsh I/O functions. `tests/test_public_api_docs.py` keeps `__all__`, the README and `docs/api` in agreement.

## Added

- `triangulate(..., medial_method=None)` adds an optional channel-width size contribution. `"grid"` uses the medial-axis grid method of the 2012 port, `"octree"` the octree leaf graph, and `"vdt"` the vector distance transform with corner pruning of [Kang and Kubatko (2024)](https://doi.org/10.5194/gmd-17-1603-2024), in the new module `admesh.medial_vdt`. The default `None` leaves output unchanged, and the locked stage modules are not modified. `scripts/bench_medial.py` compares the three methods on WNAT and ENPAC; `"vdt"` stays opt-in because it does not beat both baselines on every criterion (results in `benchmarks/medial_vdt.json` and `benchmarks/medial_vdt.md`).
- A registry mesh that is registered but not hosted (for example, a license that does not allow a hosted copy) fails with `valence_domains.MeshNotHostedError` before any download is attempted, on `valence-domains` releases that define it. Its message names the mesh and says it is not hosted. Older releases keep their behaviour.
- Valence manifest 0.4-ready; 0.3 is still supported. Registry lookups run through `admesh._valence_compat`, which picks the group API, the manifest object or the Domain-only API by feature detection. `list_available_domains()` also lists Collections, and aliases and Collections load by name. Domain metadata reports both `continent` and `region`, and mesh metadata both `format` and `type`.
- `triangulate_batch(domains, n_jobs=None, **kwargs)` meshes several domains on a process pool. Results come back in input order and are bit-identical to a serial `triangulate` loop. On 8 WNAT meshes (94,777 nodes each), 8 workers run 5.09x faster than the serial loop; small meshes gain less because each worker takes about 0.5 s to start.
- `scripts/bench_batch.py --wnat` runs the gate: at least 4.0x at 8 workers on 8 WNAT meshes. Results and figure are in `benchmarks/results/batch_wnat.json` and `benchmarks/results/batch_wnat.png`.

## Fixed

- `scripts/bench_batch.py` warms the Numba cache before timing the serial baseline. A cold baseline had inflated an earlier speedup report (2.91x).
